## 1. งานนี้ทำอะไรบ้าง

พูดง่าย ๆ คือ **"มีผู้ช่วยอ่านข่าวแทนเราทุกเช้า แล้วสรุปมาให้ในแชต"**

ทุกวันตอน 06:30 น. ระบบจะทำงานเองโดยไม่ต้องกดอะไร ดังนี้

1. **ดึงข่าว** ที่เกี่ยวกับทองคำ ค่าเงิน และหุ้นเทค จาก 4 แหล่ง
   - Google News (ค้นด้วยคำว่า XAUUSD, gold, EURUSD, euro dollar, tech stocks, Nasdaq)
   - FXStreet (ข่าว Forex และทองคำ)
   - CNBC (ข่าวตลาดและหุ้น)
   - Federal Reserve หรือธนาคารกลางสหรัฐ (ประกาศและแถลงการณ์)
2. **คัดกรองข่าว** เก็บเฉพาะข่าวภายใน 24 ชั่วโมงที่ผ่านมา ตัดข่าวซ้ำออก และเรียงจากใหม่ไปเก่า
3. **ให้ AI สรุป** เป็นภาษาไทย แบ่งเป็น 4 หัวข้อ
   - 🌍 ภาพรวมตลาด
   - 🥇 XAUUSD (ทองคำเทียบดอลลาร์)
   - 💶 EURUSD (ยูโรเทียบดอลลาร์)
   - 💻 หุ้นเทค
4. **ส่งสรุปเข้า Discord** ในห้องที่เราตั้งไว้

ในข้อความสรุป AI ถูกสั่งให้
- แยก **ข้อเท็จจริง** (เกิดอะไรขึ้น) ออกจาก **ความเห็น/การวิเคราะห์** ให้ชัดเจน
- ใส่ **ชื่อแหล่งข่าว เวลา (เวลาไทย) และลิงก์** ให้กดไปอ่านต้นฉบับได้
- **ไม่แนะนำให้ซื้อหรือขาย** สินทรัพย์ใด ๆ
- ปิดท้ายด้วยข้อความว่าเป็นข้อมูลเพื่อการศึกษา

## 2. เกิดผลดีอย่างไร ช่วยใครได้บ้าง

### ผลดีที่ได้

| ก่อนมีระบบ | หลังมีระบบ |
|---|---|
| ต้องเปิดหลายเว็บไล่อ่านข่าวเองทุกเช้า | ข่าวสำคัญถูกรวมไว้ในข้อความเดียว |
| ข่าวภาษาอังกฤษ อ่านนาน | ได้สรุปภาษาไทย อ่านจบในไม่กี่นาที |
| เจอข่าวเดิมซ้ำจากหลายเว็บ | ระบบตัดข่าวซ้ำให้แล้ว |
| แยกยากว่าอะไรคือข่าวจริง อะไรคือความเห็น | สรุปแยกข้อเท็จจริงกับความเห็นให้ |
| อาจลืมเช็กข่าวก่อนตลาดเปิด | ข้อความเด้งใน Discord ทุกเช้าอัตโนมัติ |

นอกจากนี้ทุกข้อในสรุปมีลิงก์ต้นทาง จึงตรวจสอบย้อนกลับได้เสมอ ไม่ต้องเชื่อ AI อย่างเดียว

### ช่วยใครได้บ้าง

- **นักลงทุนรายย่อยหรือคนที่เพิ่งเริ่มศึกษา** ที่อยากติดตามทอง ค่าเงิน และหุ้นเทค แต่มีเวลาน้อย
- **คนทำงานประจำ** ที่อยากรู้ภาพรวมตลาดก่อนเริ่มวัน
- **กลุ่มเพื่อนหรือชุมชนที่ศึกษาการลงทุนด้วยกัน** แชร์สรุปเดียวกันในห้อง Discord
- **คนที่อยากเรียนรู้การทำ Automation และ AI** ใช้เป็นตัวอย่างงานจริงที่ไม่ต้องเขียนโค้ดมาก

## 3. ขั้นตอนและ Flow การทำงาน

ระบบสร้างด้วย **n8n** ซึ่งเป็นเครื่องมือทำ Automation แบบลากต่อกล่อง (แต่ละกล่องเรียกว่า **Node**) ข้อมูลจะไหลจากกล่องหนึ่งไปอีกกล่องหนึ่งตามลูกศร

### ภาพรวม Flow

```
 ⏰ Schedule Trigger (ทุกวัน 06:30 น. เวลาไทย)
        │
        ├──► 📰 Google News RSS ──► ✏️ Edit Fields (ใส่ชื่อแหล่ง + เวลาไทย)
        ├──► 📰 FXStreet RSS    ──► ✏️ Edit Fields
        ├──► 📰 CNBC RSS        ──► ✏️ Edit Fields
        └──► 📰 Federal Reserve ──► ✏️ Edit Fields
                                        │
                                        ▼
                               🔗 Merge (รวมข่าวทุกแหล่ง)
                                        │
                                        ▼
                         🕐 Filter (เก็บเฉพาะข่าวใน 24 ชม.)
                                        │
                                        ▼
                      🧹 Remove Duplicates (ตัดข่าวหัวข้อซ้ำ)
                                        │
                                        ▼
                        ↕️ Sort (เรียงข่าวใหม่ → เก่า)
                                        │
                                        ▼
                    🤖 Google Gemini (สรุปเป็นภาษาไทย 4 หัวข้อ)
                                        │
                                        ▼
                  📤 HTTP Request (ส่งข้อความเข้า Discord Webhook)
                                        │
                                        ▼
                             💬 ข้อความสรุปใน Discord
```

### อธิบายทีละขั้น

| ขั้น | Node | ทำอะไร | ตั้งค่าสำคัญ |
|---|---|---|---|
| 1 | **Schedule Trigger** | ตั้งนาฬิกาปลุกให้ระบบเริ่มทำงาน | ทุกวัน 06:30 น. (เวลาไทยต้องตั้ง Timezone เป็น `Asia/Bangkok`) |
| 2 | **RSS Read** (4 ตัว) | ไปดึงรายการข่าวจากแต่ละแหล่ง | Google News ใช้ลิงก์ค้นหาแบบด้านล่าง ส่วนแหล่งอื่นใช้ลิงก์ RSS ของเว็บนั้น |
| 3 | **Edit Fields** | ติดป้ายว่าข่าวมาจากแหล่งไหน และแปลงเวลาเป็นเวลาไทย | เพิ่มช่อง `source` และเวลาไทย |
| 4 | **Merge** | รวมข่าวจากทุกแหล่งให้อยู่ในกองเดียว | |
| 5 | **Filter** | เก็บเฉพาะข่าวที่ออกภายใน 24 ชั่วโมง | ดูจากช่อง `isoDate` |
| 6 | **Remove Duplicates** | ตัดข่าวที่หัวข้อซ้ำกันออก | โหมด *Remove Items Repeated Within Current Input* เทียบช่อง `title` |
| 7 | **Sort** | เรียงข่าวล่าสุดขึ้นก่อน | เรียง `isoDate` แบบ Descending (ใหม่ → เก่า) |
| 8 | **Google Gemini** | ให้ AI อ่านข่าวทั้งหมดแล้วสรุป | โมเดลตระกูล Flash, เปิด *Execute Once* และ *Retry On Fail*, Max Tokens `8192`, ปิด *Output as JSON* |
| 9 | **HTTP Request** | ส่งข้อความสรุปเข้า Discord | Method `POST` ไปที่ Discord Webhook URL |

**ลิงก์ค้นหา Google News ที่ใช้** (ค้นทุกคำในครั้งเดียว และเอาเฉพาะข่าว 1 วันล่าสุด)

```
q=(XAUUSD OR gold OR EURUSD OR "euro dollar" OR "tech stocks" OR Nasdaq) when:1d
```

> 💡 ทำไมต้องเปิด **Execute Once** ที่ Gemini?
> เพราะเราต้องการให้ AI สรุปข่าว "ทั้งกอง" ในครั้งเดียว ถ้าไม่เปิด n8n จะส่งข่าวให้ AI ทีละข่าว แล้วได้ข้อความสรุปออกมาหลายสิบข้อความแทน

### ขั้นตอน A: เลือกที่รัน n8n (ต้องเปิดตลอด 24 ชั่วโมง)

ระบบต้องทำงานตอน 06:30 ทุกเช้า ดังนั้น n8n ต้องอยู่บนเครื่องที่ **เปิดตลอดเวลา** ถ้ารันบนคอมพิวเตอร์ส่วนตัวแล้วปิดเครื่อง ระบบจะไม่ทำงาน

| ตัวเลือก | เหมาะกับใคร | หมายเหตุ |
|---|---|---|
| **n8n Cloud** | มือใหม่ ไม่อยากดูแลเซิร์ฟเวอร์ | สมัครแล้วใช้ได้เลย มีค่าบริการ |
| **VPS + Docker** | คนที่พอใช้คำสั่ง Terminal ได้ | ถูกกว่าในระยะยาว ต้องดูแลเอง |
| **Railway** | อยากได้ความง่ายแต่ยังกำหนดค่าเองได้ | มีเทมเพลต n8n ให้กดติดตั้ง |
| ~~Vercel~~ | ❌ ไม่เหมาะ | ออกแบบมาสำหรับเว็บ ไม่ได้รันโปรแกรมค้างไว้ตลอด |

**ถ้าติดตั้งเองด้วย Docker (VPS)** ใช้คำสั่งประมาณนี้

```bash
# 1) สร้างที่เก็บข้อมูลถาวร (ปิดเปิดเครื่องแล้ว Workflow ไม่หาย)
docker volume create n8n_data

# 2) รัน n8n
docker run -d --name n8n --restart unless-stopped \
  -p 5678:5678 \
  -e GENERIC_TIMEZONE=Asia/Bangkok \
  -e TZ=Asia/Bangkok \
  -e N8N_ENCRYPTION_KEY=ใส่รหัสยาวๆที่สุ่มขึ้นมาเอง \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n
```

ค่าที่ **ต้องตั้งให้ถูก** ไม่ว่าจะใช้แบบไหน

- `GENERIC_TIMEZONE=Asia/Bangkok` เพื่อให้ 06:30 เป็นเวลาไทยจริง ไม่ใช่เวลาอังกฤษ
- `N8N_ENCRYPTION_KEY` คือกุญแจที่ n8n ใช้เข้ารหัส API Key ที่เราบันทึกไว้ **ต้องจดเก็บไว้ในที่ปลอดภัย** ถ้าหายหรือเปลี่ยน n8n จะเปิด Credential เดิมไม่ได้
- **Volume** (`-v n8n_data:...`) เพื่อให้ข้อมูลไม่หายเวลารีสตาร์ต

### ขั้นตอน D: สร้าง Workflow ใน n8n

สร้าง Workflow ใหม่ แล้วเพิ่ม Node ตามลำดับในหัวข้อที่ 3 จุดที่มือใหม่มักพลาดมีดังนี้

**1. Schedule Trigger**
- Trigger Interval: Days, Hour: 6, Minute: 30

**2. RSS Read (4 ตัว)**
- ลากเส้นจาก Schedule Trigger ไปทั้ง 4 ตัว
- ตัว Google News ใช้ลิงก์ Google News RSS พร้อมคำค้นในหัวข้อที่ 3
- ตัวอื่นใช้ลิงก์ RSS ที่ได้จากหน้าเว็บของ FXStreet, CNBC และ Federal Reserve

**3. Edit Fields (ต่อท้าย RSS แต่ละตัว)**
- เพิ่มช่อง `source` ใส่ชื่อแหล่งข่าว เช่น `CNBC`
- เพิ่มช่องเวลาไทย แปลงจาก `isoDate`

**4. Merge** รวมทุกเส้นเข้าด้วยกัน

**5. Filter** เงื่อนไข: `isoDate` อยู่หลังเวลา "ตอนนี้ลบ 24 ชั่วโมง"

**6. Remove Duplicates**
- Operation: *Remove Items Repeated Within Current Input*
- Compare: เลือกช่อง `title`

**7. Sort** Field: `isoDate`, Order: Descending

**8. Google Gemini**
- Credential: Google Gemini (PaLM) API ที่สร้างในขั้นตอน B
- Model: ตระกูล Flash
- **System Instruction** สั่งให้
  - สรุปเป็นภาษาไทย 4 หัวข้อ: ภาพรวมตลาด / XAUUSD / EURUSD / หุ้นเทค
  - แยกข้อเท็จจริงกับความเห็น
  - ใส่แหล่งข่าว เวลาไทย และลิงก์
  - ห้ามแนะนำซื้อขาย
  - ปิดท้ายด้วยข้อความว่าเป็นข้อมูลเพื่อการศึกษา
- Settings: เปิด **Execute Once** และ **Retry On Fail**
- Options: Max Tokens = `8192`, **ปิด** Output as JSON

**9. HTTP Request (ส่งเข้า Discord)**
- Method: `POST`
- URL: Discord Webhook URL จากขั้นตอน C
- Send Body: เปิด → *Using Fields Below*
  - Name: `content`
  - Value: `{{ $json.content.parts[0].text }}`

### ขั้นตอน E: ทดสอบและเปิดใช้งาน

1. กดปุ่ม **Test Workflow** (หรือ Execute Workflow) ใน n8n
2. ดูว่ากล่องทุกกล่องเป็นสีเขียว และมีข้อความเด้งเข้า Discord
3. ถ้าข้อความถูกต้อง ให้กดสวิตช์ **Active** มุมขวาบน
4. ตั้งแต่นี้ระบบจะทำงานเองทุกเช้า 06:30 น.

### แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่น่าจะเป็น | วิธีแก้ |
|---|---|---|
| ระบบทำงานผิดเวลา (เช่นตีหนึ่งครึ่ง) | Timezone ยังไม่ใช่เวลาไทย | ตั้ง `GENERIC_TIMEZONE=Asia/Bangkok` และเช็ก Timezone ใน Settings ของ Workflow |
| Discord ไม่ได้รับข้อความ / Error 400 | ข้อความยาวเกิน **2,000 ตัวอักษร** (ขีดจำกัดของ Discord ต่อ 1 ข้อความ) | ปรับ System Instruction ให้สรุปสั้นลง |
| ได้ข้อความสรุปหลายสิบข้อความ | ลืมเปิด Execute Once ที่ Gemini | เปิด Execute Once |
| ข้อความใน Discord ว่างหรือเป็น `undefined` | Value ใน HTTP Request ไม่ตรงกับรูปแบบผลลัพธ์ของ Gemini | ตรวจว่าใช้ `{{ $json.content.parts[0].text }}` และปิด Output as JSON |
| Gemini error เป็นบางวัน | โควตาเต็มหรือเซิร์ฟเวอร์ช้า | Retry On Fail ช่วยลองใหม่ให้ ถ้ายังไม่ได้ให้เช็กโควตา |
| ไม่มีข่าวเลย | Filter 24 ชม. ตัดหมด หรือลิงก์ RSS เสีย | กดทดสอบทีละกล่องเพื่อดูว่าข่าวหายไปที่กล่องไหน |
| Credential ใช้ไม่ได้หลังย้ายเครื่อง | `N8N_ENCRYPTION_KEY` ไม่ตรงกับของเดิม | ใช้ Key เดิมที่จดเก็บไว้ |

### การนำไปปรับใช้ต่อ

- **อยากติดตามสินทรัพย์อื่น** แก้คำค้นใน Google News และหัวข้อใน System Instruction
- **อยากเปลี่ยนเวลา** แก้ที่ Schedule Trigger
- **อยากเพิ่มแหล่งข่าว** เพิ่ม RSS Read + Edit Fields อีกชุด แล้วต่อเข้า Merge
- **อยากส่งไปหลายห้อง** เพิ่ม HTTP Request อีกตัวด้วย Webhook URL ของห้องนั้น
